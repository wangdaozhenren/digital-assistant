## L1 常识卡（12 张）

### [L1] CPU 怎么看（i5/R7 是什么）

- **一句话结论**：CPU 型号第一位是代数（如 i5-14 是 14 代），第二位起是档位；同代数字越大越强，跨代看"天梯"对比。
- **依据/来源**：Intel/AMD 官方产品线命名规则。
- **边界声明**：信息参考。
- **最后核验**：2026-09。

### [L1] 内存（RAM）8G vs 16G 区别

- **一句话结论**：内存管"同时开多少"——日常刷网页 8G 够用，多开/剪辑/游戏建议 16G 起；手机 8G 日常够，12G 用得更久。
- **依据/来源**：计算机硬件通识。
- **边界声明**：因使用场景而异。
- **最后核验**：2026-09。

### [L1] 存储（ROM/硬盘）256G vs 512G 区别

- **一句话结论**：存储管"存多少"——照片/视频/游戏占空间大；手机 256G 日常够，拍视频/装多游戏选 512G。
- **依据/来源**：计算机硬件通识。
- **边界声明**：因使用量而异。

### [L1] 屏幕刷新率 60Hz vs 120Hz

- **一句话结论**：刷新率越高滑动越跟手（120Hz>60Hz），但耗电略增；日常 60Hz 够，游戏/滑动多建议 120Hz。

## L4 实操卡（7 张）

### [L4] 新手机数据迁移步骤

- **一句话结论**：用品牌官方迁移工具（如"手机克隆""一键迁移"），旧机扫码连同一热点，选数据开始迁移。
- **步骤**：
  1. 新旧机连同一 Wi-Fi/热点；
  2. 新机开机选"从旧设备导入"；
  3. 旧机扫新机二维码；
  4. 勾选要迁移的数据（通讯录/照片/App）；
  5. 等待完成，期间不切屏。
- **常见错误**：用蓝牙慢；中途断开。
- **适用边界**：跨品牌用对应官方工具；加密数据需密码。
- **标注**：通用经验，非官方标准。
- **最后核验**：2026-09。

### [L4] 新电脑初始设置

- **一句话结论**：开机→登录账号→系统更新→装杀毒/驱动→迁移数据。
- **步骤**：
  1. 按提示连 Wi-Fi、登录微软/苹果账号；
  2. Windows：设置→Windows 更新，打全补丁；
  3. 装品牌官方驱动（官网下载或品牌管家）；
  4. 卸载预装第三方软件（设置→应用）；
  5. 迁移旧文件。
- **常见错误**：连陌生公共 Wi-Fi 注册账号。
- **适用边界**：新电脑首次开机建议插电。
- **标注**：通用经验。
- **最后核验**：2026-09。

### [L4] 电池保养习惯

- **一句话结论**：别等电量耗尽再充、别长期满电插着、避免高温。
- **步骤**：
  1. 20%~80% 之间随用随充；
  2. 长期插电开"优化电池充电"；
  3. 边充边玩大型游戏发热大，尽量避免；
  4. 夏天别放车里暴晒；
  5. 用原装/认证充电器。
- **常见错误**：用到自动关机再充。
- **适用边界**：锂电池通用经验。
- **标注**：通用经验，非官方标准。
- **最后核验**：2026-09。

### [L4] 空调滤网清洗

- **一句话结论**：两周~一个月洗一次滤网，制冷差/有异味先洗滤网。
- **步骤**：
  1. 关机断电；
  2. 掀开面板取下滤网；
  3. 清水冲/软刷轻刷，阴干不暴晒；
  4. 装回试机。
- **常见错误**：没干透装回（发霉味）。
- **适用边界**：只洗滤网，不拆机内机；制冷/加氟找售后。
- **标注**：通用经验。
- **最后核验**：2026-09。

### [L4] 冰箱除味/清理

- **一句话结论**：每月清理一次，过期食物丢掉，活性炭/除味盒辅助。
- **步骤**：
  1. 断电、清空；
  2. 温水+小苏打擦内壁；
  3. 过期/变质食物丢弃；
  4. 放除味盒/活性炭；
  5. 生熟分层、密封盒保存。
- **常见错误**：生熟混放不密封。
- **适用边界**：不拆机除冰（手动除冰断电即可）。
- **标注**：通用经验。
- **最后核验**：2026-09。

### [L4] 洗衣机槽清洁

- **一句话结论**：2~3 个月用洗衣机槽清洁剂自清洁一次。
- **步骤**：
  1. 倒洗衣机槽清洁剂入筒；
  2. 选"筒清洁/自清洁"程序（空筒运行）；
  3. 结束开盖晾干；
  4. 橡胶圈擦水渍防霉。
- **常见错误**：有衣服还开自清洁。
- **适用边界**：只清洁外筒，不拆机。
- **标注**：通用经验。
- **最后核验**：2026-09。

### [L4] 常见故障自检

- **一句话结论**：先查电源/插头/重启，再查网络，仍异常找售后。
- **步骤**：
  1. 不开机：查插座/插头/电源线，换插座试；
  2. 连不上网：重启路由器/设备，忘密码重连；
  3. 卡顿：重启、关后台、清存储；
  4. 屏幕不亮：查亮度/信号线；
  5. 仍异常：品牌官方售后，不自行拆机。
- **常见错误**：一有问题就刷机/重装。
- **适用边界**：拆机/内部故障找专业。
- **标注**：通用经验。
- **最后核验**：2026-09。
