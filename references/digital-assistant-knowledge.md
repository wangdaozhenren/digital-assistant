## 一、平台路由细则

| 场景 | 平台顺序 | 说明 |
|---|---|---|
| 手机/电脑 | 京东 → 淘宝/天猫 → 拼多多 | 京东自营/品牌旗舰优先；官网价作基准 |
| 大家电（冰箱/洗衣机/空调/电视） | 京东 → 天猫 → 苏宁 | 注意安装费/配送范围 |
| 小家电 | 京东 → 淘宝 → 拼多多 | 注意是否含发票 |
| 配件/线材 | 京东 → 淘宝 → 拼多多 | 同规格比价 |

## 二、计价口径（到手价）

### 2.1 到手价公式

```
到手价 = 标价 − 平台补贴 − 国补（按政策口径）− 以旧换新抵扣
```

- 标价：商品页显示价；
- 平台补贴：券/满减/百亿补贴；
- 国补：按当期政策（如数码/家电购新补贴），注明"以下单时为准"；
- 以旧换新：旧机估价，与国补能否叠加按官方规则。

### 2.2 分开列的费用

- **安装费**：空调/电视/热水器等可能另收，分开列；
- **延保**：是否需要单独购买，标注费用；
- **赠品价值**：不折算进价格，单独说明；
- **配送费**：大家电是否含送装一体。

### 2.3 同轨比较条件

必须同时满足：**同一型号 + 同一配置（CPU/内存/存储/屏幕/接口）+ 同渠道版本**，才同轨比到手价。

| 易混淆项 | 说明 |
|---|---|
| 同型号不同存储 | 8G+128G vs 16G+512G 不同轨 |
| 同型号不同处理器 | i5 vs i7 不同轨 |
| 官标 vs 渠道定制 | 部分品牌有"电商特供"配置，列清 |
| 全新 vs 官翻 | 不同轨 |

## 三、双规格标题防假低价

- 标题写"低至 ¥XX"通常是最低配/入门款 → 必开卡核实；
- 点进商品页选到用户要的具体配置，读真实价；
- 列表用真实配置的到手价。

## 四、参数对齐速查

| 品类 | 必须对齐的关键参数 |
|---|---|
| 手机 | 型号 + 内存(GB) + 存储(GB) + 屏幕尺寸 + 版本（国行/海外） |

## 五、国补/以旧换新要点

- 国补政策每次回答前核实官方公告；
- 以旧换新估价：同型号在爱回收/转转/品牌官方估价对比；
- 标注"政策实时变动，以下单时官方页面为准"。

## 七、国补政策细节（示例，以下单时官方页面为准）

- **手机/平板**：通常限单价 6000 元以下产品，补贴比例约 15%，单台封顶约 500 元；超过 6000 元的机型不参与。
- **电脑（笔电/台式）**：一般无单价上限门槛，补贴比例约 15%，单台封顶约 1500 元。
- **领取流程**：在地方政务/补贴平台（如"京通""郑好办"等各地小程序）领补贴资格码 → 到合作电商（京东/天猫等）下单时绑定该码 → 结算自动扣减；报告提示"各地补贴入口与额度不同，以当地最新公告为准"。
- **国补叠加套路**：先涨后降（补贴前先抬价）、限定型号/指定仓库、限量名额；比价时要对比"补贴前日常价"，避免被假优惠忽悠。

## 八、选购参数与保养

- **手机内存/存储决策**：8G 内存够用但后台杀应用快，12G 更从容；256G 存照片视频偏紧，512G 更稳。按预算与使用强度选，不必盲目上顶配。
- **笔记本参数解读**：CPU 看型号代数（同代数字越大越强）、内存频率、屏幕色域（100% sRGB 起步，设计需高色域）、续航（Wh 数）；不唯跑分，按用途（办公/游戏/设计）选。
- **家电能效与电费测算**：能效等级 1 级最省电；电费(度/年) ≈ 标注的"年耗电量(kWh)" × 当地电价(约 0.5~0.6 元/度)。空调/冰箱长期用，1 级与 3 级差价几年可通过电费省回。
- **家电清洗保养周期**：空调滤网每 2~4 周清洗、深度清洗每年 1 次；冰箱冷凝器/密封条定期清洁；洗衣机筒自洁每 1~2 个月；油烟机每 3~6 个月。保养差既费电又缩短寿命。
