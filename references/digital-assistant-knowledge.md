# 3C数码家电助手 · 领域知识（计价口径与平台规则）

> 本文件是比价采集的口径依据，第 6 步口径归一必读。

## 一、平台路由细则

| 场景 | 平台顺序 | 说明 |
|---|---|---|
| 手机/电脑 | 京东 → 淘宝/天猫 → 拼多多 | 京东自营/品牌旗舰优先；官网价作基准 |
| 大家电（冰箱/洗衣机/空调/电视） | 京东 → 天猫 → 苏宁 | 注意安装费/配送范围 |
| 小家电 | 京东 → 淘宝 → 拼多多 | 注意是否含发票 |
| 配件/线材 | 京东 → 淘宝 → 拼多多 | 同规格比价 |

## 二、计价口径（到手价）

### 2.1 到手价公式

```
到手价 = 标价 − 平台补贴 − 国补（按政策口径）− 以旧换新抵扣
```

- 标价：商品页显示价；
- 平台补贴：券/满减/百亿补贴；
- 国补：按当期政策（如数码/家电购新补贴），注明"以下单时为准"；
- 以旧换新：旧机估价，与国补能否叠加按官方规则。

### 2.2 分开列的费用

- **安装费**：空调/电视/热水器等可能另收，分开列；
- **延保**：是否需要单独购买，标注费用；
- **赠品价值**：不折算进价格，单独说明；
- **配送费**：大家电是否含送装一体。

### 2.3 同轨比较条件

必须同时满足：**同一型号 + 同一配置（CPU/内存/存储/屏幕/接口）+ 同渠道版本**，才同轨比到手价。

| 易混淆项 | 说明 |
|---|---|
| 同型号不同存储 | 8G+128G vs 16G+512G 不同轨 |
| 同型号不同处理器 | i5 vs i7 不同轨 |
| 官标 vs 渠道定制 | 部分品牌有"电商特供"配置，列清 |
| 全新 vs 官翻 | 不同轨 |

## 三、双规格标题防假低价

- 标题写"低至 ¥XX"通常是最低配/入门款 → 必开卡核实；
- 点进商品页选到用户要的具体配置，读真实价；
- 列表用真实配置的到手价。

## 四、参数对齐速查

| 品类 | 必须对齐的关键参数 |
|---|---|
| 手机 | 型号 + 内存(GB) + 存储(GB) + 屏幕尺寸 + 版本（国行/海外） |
| 笔记本 | CPU 型号 + 内存(GB) + 硬盘(GB) + 显卡 + 屏幕（刷新率/色域） |
| 电视 | 尺寸(英寸) + 分辨率(4K/8K) + 刷新率 + 面板类型 + 内存 |
| 空调 | 匹数 + 能效等级 + 变频/定频 + 冷暖 + 安装服务 |
| 冰箱 | 容量(L) + 门型 + 制冷方式 + 能效 |
| 洗衣机 | 容量(kg) + 类型(滚筒/波轮) + 转速 + 烘干功能 |

## 五、国补/以旧换新要点

- 国补政策每次回答前核实官方公告；
- 以旧换新估价：同型号在爱回收/转转/品牌官方估价对比；
- 标注"政策实时变动，以下单时官方页面为准"。
